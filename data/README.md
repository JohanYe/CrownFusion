# FDI 16 Crown Dataset

The dataset is available on DTU Data: <https://doi.org/10.11583/DTU.35039497>

It contains 11,513 intraoral scans of prepared upper right first molars (FDI 16), each paired with the final crown
restoration and the surrounding dentition, split into 9,513 / 1,000 / 1,000 cases for train / val / test.

Download `CrownFusion.zip` (23.5 GB) from the dataset page and extract it. It unpacks to `CrownFusion/`, which is
the dataset root used by the training code (see "Data layout" in the [main README](../README.md)). File formats are
described in `readme.txt` inside the archive.
